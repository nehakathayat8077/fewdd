How the web works

Before building web pages, it helps to know what happens when someone visits one. Here is the short version, and how it maps onto this project.

  1. You type an address (like a website name) into a browser, or tap a link.
  2. The browser asks a server - a computer that stores the website's files - to send the page.
  3. The server replies with an HTML file, plus any CSS and JavaScript files it links to.
  4. The browser reads the HTML, applies the CSS, runs the JavaScript, and draws the page you see.

About this project

World Atlas is a teaching example. It was built to show, in one small real project, how a beginner web-design course fits together.

What you can learn from it

  • How HTML gives a page structure: headings, lists, tables, links, forms and images.
  • How CSS controls appearance: colours, fonts, spacing, and the box model.
  • How JavaScript adds behaviour: reading data, responding to clicks and typing, and updating the page live.
  • How the three files above are linked together into one working website.
